# gloop Homebrew Tap

Install gloop with:

```bash
brew install moto-taka/tap/gloop
```

The formula builds the `gloop` binary from the tagged Apache-2.0 source release.

## Jev CU JP

Install the CLI and register its Agent Skill:

```bash
brew install moto-taka/tap/jev-cu-jp
jev-cu-jp setup codex --clipboard
```

Copy your TypeSafe key to the clipboard before the second command. Use `claude` or `pi` instead of `codex` for those hosts. See the [Jev CU JP guide](https://github.com/moto-taka/jev-cu-jp) for Vercel AI Gateway and Computer Use setup.
